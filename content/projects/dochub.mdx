DOCHUB brings proposals, documentation, plans, and decisions into one focused document workspace. Readers can enter with a passwordless email code or open a specifically shared document using a collection code. Workspace access and document-level sharing are kept distinct, while a connected document tree helps people move through related information with context.

## What I built

- Designed workspace-scoped access and a document-code path for sharing individual documents with external readers.
- Built a passwordless sign-in flow using a six-digit email code for workspace access.
- Organized documents into a navigable tree so proposals, plans, and decisions retain their relationships.
- Developed an authoring experience with Markdown editing, preview, media selection, and document publishing states.
- Added version-aware document workflows so teams can revise content while preserving a clear publishing path.
- Created a responsive reading experience for long-form documents and shared collections.

## Engineering focus

DOCHUB demonstrates access boundaries, thoughtful document organization, a clear author-to-reader workflow, and secure sharing across internal workspaces and external recipients. The interface is designed to keep related information together while making the current document easy to read and act on.
